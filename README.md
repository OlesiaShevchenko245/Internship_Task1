#Observations Statistics
##Опис:
Проєкт виконує багатопотокову обробку астрономічних спостережень, обчислюючи статистику за вибраним полем (tags, author, location, instrument).
Програма читає вхідні JSON-файли зі спостереженнями, агрегує унікальні значення та рахує кількість появ кожного значення, а потім зберігає результат у форматі XML.
